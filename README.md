This project was created for a cybersecurity talk in 42 Madrid Programming school.

Its only purpose is to show how easy it is for an attacker to clone a website and start a phishing campaign.

The talk took place after a phishing test campaign was done to all 42 Madrid Campus students during 2022.
Obviously, the campaign was launched with full knowledge and permission of 42 Madrid Staff.

The objective of this test campaign was to demonstrate how easy will be for an attacker to steal student credentials.
